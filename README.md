# 🚀 Qwen AI Content Generator

Instantly generate professional, ready-to-publish content (LinkedIn posts, Twitter threads, emails) using the open-source **Qwen 2.5** AI model. 

### ✨ Features
- ⚡ Lightning-fast generation (runs on standard CPU)
- 🎯 Multiple content formats
- 🆓 100% free and open-source
- 🔒 Privacy-focused (no external API keys required)

### 🛠️ Tech Stack
- **Model:** Qwen/Qwen2.5-0.5B-Instruct
- **Framework:** Hugging Face Transformers
- **UI:** Gradio
- **Deployment:** Hugging Face Spaces
